# 紙・Excel名簿の照合（2026-10-31）

入口：顧客管理の「紙・Excel名簿を登録せずに照合する」→ `/admin/customers/reconcile`。

1. 店員が紙名簿の名前を1行に1人ずつ入力するか、Excelから「名前」「会員番号（任意）」の順でコピーする。電話・メール・旧ポイント残高は貼り付けない。
2. 「登録せずに照合する」を押す。1回200人・30,000文字まで。見出しは名前／氏名／お名前、2列目は会員番号／顧客コードに対応。CSVファイルの取込ではなく、名前の1列またはタブ区切りの2列に対応する。
3. 同名の複数候補、無効会員、番号と名前の不一致、未発見、貼り付け名簿内の同名・番号重複を確認する。会員番号は現在の店舗内一意ルールに合わせ、大文字小文字を区別する。
4. 候補の顧客詳細を別タブで確認し、現物名簿・店員の確認と照合する。名前の空白差は候補検索で吸収するが、同一人物と自動認定しない。
5. 未登録と確認した客だけ、通常の受付で登録する。無効客・同名客を新規客と決めつけない。紐付け先が判別できなければ保留する。

## 安全のための範囲

- スタッフ認証必須。ログインした店舗の通常顧客だけが対象。無効客も候補に含め、スタッフ用Customerは除外する。
- この機能から会員作成・統合・受付・ポイント移行・スマホ連携は行わない。会員番号と名前の一致を本人認証・復旧の許可に使わない。
- 入力した名簿と照合結果はDB・監査・URLへ保存しない。ブラウザー画面とサーバーの処理中に使う。内容を変えたら以前の結果を隠し、再照合する。
- 顧客の内部メモ・電話・メール・公開プロフィールは照合APIで取得しない。候補は1行5件まで、全件数は示す。
- 店舗の対象会員が10,000人を超える場合は処理を中止し、通常検索へ案内する。部分的な照合結果を「候補なし」と表示しない。
- 名前の照合は既存受付と共通の正規化による完全一致。異なる呼び名、旧名、表記揺れのすべてを自動検出するものではない。別名検索・店員の確認を残す。
