# スマホ基本操作の改善と確認（2026-11-16）

## メニューの操作を改善

受付や結果入力中にメニューを開いた際、元の画面へ戻りやすくする。

- 開閉ボタンに状態と閉じ方を表示し、外側タップ・Escapeでも閉じる。
- 閉じたメニューは表示・キーボード・読み上げの対象から外す。
- 開いている間は本体main領域をinertにし、背景の入力・操作とスクロールを防ぐ。
- フォーカスをメニューへ移し、Tab/Shift+Tabでメニューと閉じるボタンの範囲に保ち、閉じるとボタンへ戻す。
- 短い画面ではメニュー自体を縦スクロールできる。PC幅へ変わると背景の制限を解除する。

実装：src/components/layout/sidebar.tsx、src/app/globals.css。画面遷移先、認証・所属店舗・Role判定、DBの処理は変更しない。
