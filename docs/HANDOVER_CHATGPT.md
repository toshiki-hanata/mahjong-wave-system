## 4. 承認済みの業務方針

- 日付は深夜0時で分割せず、営業開始から営業終了までを1営業日とする。
- フリー1本は「1卓で半荘が1回終了したら1本」。説明用の現在単価は2,500円。通常のPOSレジ・決済機能は不要。
- スタッフも着席可能で、料金はお客さんと同様。店舗の本数はスタッフ人数にかかわらず1卓1半荘1本。
- スタッフの参加本数は別途記録。当面は顧客向けポイント・ランキングから除外するが、将来変更の可能性を残す。
- セットは代表者と卓で管理し、人数分の会員登録は不要。卓・開始終了予定時刻の予約も追加予定。料金と丸め方は未決定。
- アウトはスタッフへの前貸し。サービス料はポイント特典や新規特典などで、お客さんへ現金で渡すゲーム代バック。
- 番責、前貸し・返済、経費、現金、在庫、勤務、日報・Excel/CSVは今後の機能。独立したAT勤怠システムとは分ける。

### 独自ポイントの承認済み判定案（実製品の自動付与は未実装）

| 条件 | ポイント |
| --- | --- |
| 来店 | 同じ営業日につき1回、1pt。退店・再来店で重複しない |
| 連続来店 | 直前に営業した日にも来店していれば追加1pt。営業しなかった日は途切れ扱いにしない |
| その営業日の5ゲームごと | 1pt。10ゲームなら2pt |
| 1位 | 1回ごと1pt |
| 役満 | 店員の記録1回につき5pt |

旧残高移行・手動調整・訂正はOWNER／MANAGER、決定済み特典の交換は全スタッフ。消費後に結果訂正した場合の不足残高、取消、特典単価、営業時刻訂正時の再計算などは未確定。
