スマホから見る

  1. PCのmockフォルダーで node serve.cjs、またはstart-mock.cmdを実行。
  2. PCは http://localhost:4177。
  3. PCと同じWi-Fiのスマホから http://PCのIPv4アドレス:4177。localhostはPCだけのアドレスです。
  4. Windowsのネットワーク制限やゲストWi-Fiの端末隔離があると接続できません。今回ファイアウォールは変更していません。インターネット公開もしていません。
